プライバシーポリシー

「AI Genkai Lab Analytics」（以下「本ツール」）は、YouTubeチャンネル「AIの限界ラボ」の運用者本人が、自身のチャンネルのアナリティクスを確認するためだけに使用する個人用のツールです。本ポリシーは、本ツールが取得する情報とその取り扱いについて定めるものです。

取得する情報

本ツールは、YouTube Analytics API および YouTube Data API を通じて、運用者本人のチャンネルに関する統計情報（視聴回数、視聴時間、登録者数の推移など）とチャンネル情報を取得します。権限は読み取り専用（yt-analytics.readonly / youtube.readonly）であり、本ツールがチャンネルの内容を変更することはありません。

利用目的

取得した情報は、チャンネル運営の分析のためにのみ使用します。それ以外の目的では使用しません。

保存と管理

取得した情報は、運用者本人の管理する環境にのみ保存します。

第三者への提供

取得した情報を第三者へ提供・販売することはありません。

データの削除

Googleアカウントの設定（「サードパーティ製アプリとサービス」）から本ツールのアクセス権を取り消すことで、情報の取得を停止できます。保存済みのデータは、運用者本人の環境から削除します。削除に関するご連絡は、下記の問い合わせ先までお願いします。

問い合わせ先

YouTubeチャンネル「AIの限界ラボ」の運用者宛てにご連絡ください。
