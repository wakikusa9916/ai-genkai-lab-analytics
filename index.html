AI Genkai Lab Analytics

「AI Genkai Lab Analytics」は、YouTubeチャンネル「AIの限界ラボ」の運用者本人が、自身のチャンネルのアナリティクス（統計情報）を確認するためだけに使用する個人用のツールです。

このツールは、YouTube Analytics API と YouTube Data API を読み取り専用で利用し、チャンネルの視聴回数・視聴時間・登録者数などの統計情報を取得して、チャンネル運営の分析にのみ使用します。一般の利用者向けに公開・提供するサービスではありません。

取得した情報の取り扱いについては、プライバシーポリシーをご覧ください。
